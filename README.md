# Prep Master

Updated mobile-first education website with:

- Prep Master branding and supplied logo icon
- Three-dot header menu: Batches, My Batches, Join Telegram, Contact Owner
- Four-item bottom navigation: Community, My Batches, Batches, AI Doubts
- Community and AI Doubts show a “This feature is coming soon” screen
- Enroll flow with Congratulations popup
- Enrolled batches saved in browser localStorage and shown in My Batches
- Searchable batch listing powered by the existing `/api/batches` source

## Optional environment variables

`NEXT_PUBLIC_TELEGRAM_URL` — Telegram channel URL opened by Join Telegram.

`NEXT_PUBLIC_OWNER_CONTACT` — email address or full contact URL used by Contact Owner.
